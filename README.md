# AI Screen Assistant

Десктопный ассистент для **Windows 10/11 x64**: выделение области, локальное распознавание текста Windows OCR, редактирование и потоковый ответ GigaChat. PySide6, асинхронный httpx, qasync, Windows RegisterHotKey и Credential Manager. Это исходный проект; Windows-сборка в данной Linux-среде не выполнялась.

## Установка и запуск на Windows

1. Установите **Python 3.12 x64** с python.org (включая Python Launcher).
2. Установите русский и английский компоненты OCR Windows. В административном PowerShell:

   ```powershell
   Add-WindowsCapability -Online -Name Language.OCR~~~ru-RU~0.0.1.0
   Add-WindowsCapability -Online -Name Language.OCR~~~en-US~0.0.1.0
   ```

   Распознавание доступно локально и не требует скачивания моделей приложением. Для изменения системных компонентов нужны права администратора; для работы приложения — нет.
3. В папке проекта:

   ```powershell
   py -3.12 -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   .venv\Scripts\python.exe packaging\check_ocr.py
   .venv\Scripts\python.exe main.py
   ```

При первом запуске открываются настройки. После добавления ключа приложение работает в системном трее. Если ключ уже сохранён, обычный запуск уходит в трей. `--tray` используется автозагрузкой. Повторный экземпляр не запускается.

## Подключение GigaChat

**Перевыпустите ключ, если он был опубликован в чате, переписке или репозитории.** Предоставленный в сообщении ключ не включён в проект и не использовался для внешних запросов.

В личном кабинете GigaChat получите **Authorization Key** — Base64-представление пары идентификатора и секрета. Вставьте его в настройки (префикс `Basic` допускается), выберите scope своего тарифа: `GIGACHAT_API_PERS`, `GIGACHAT_API_B2B` или `GIGACHAT_API_CORP`. Нажмите «Проверить подключение и модели», выберите доступную модель и сохраните настройки. Проверка несохранённого ключа не сохраняет его автоматически.

Ключ хранится в **Windows Credential Manager** в учётных данных `AI Screen Assistant / GigaChat`; JSON содержит только обычные настройки. Токен находится в памяти, обновляется перед истечением срока и один раз после HTTP 401. Для удаления ключа используйте флажок в настройках или Windows Credential Manager.

OAuth выполняется через `POST https://ngw.devices.sberbank.ru:9443/api/v2/oauth`, с новым UUID `RqUID` и form-urlencoded `scope`. API: `https://api.giga.chat/v1`, методы `/models`, `/chat/completions`, `/files` и `/files/{id}/delete`. Протокол сверялся с [официальным SDK](https://github.com/ai-forever/gigachat/tree/d3c5ff27b38b350c7cc8f20fb6d5d93d98ece4a7/src/gigachat) (auth.py, chat.py, files.py, settings.py). [Официальная документация](https://developers.sber.ru/docs/ru/gigachat/overview) при проверке из облачной среды ответила HTTP 403. Реальный запрос GigaChat в облаке не выполнялся.

Требуется HTTPS-доступ к `ngw.devices.sberbank.ru` на порту **9443** и `api.giga.chat` на порту 443. Для установки Python-зависимостей — `pypi.org` и `files.pythonhosted.org`. Ограничения облачной сети не менялись.

**TLS проверяется всегда.** Используется системное хранилище Windows через truststore. Если серверу требуется корневой сертификат НУЦ Минцифры, установите его из официального источника в доверенное хранилище Windows либо укажите доверенный PEM-файл в настройках. Не скачивайте сертификаты из неизвестных источников и не отключайте проверку TLS. Пользовательский CA-файл храните по постоянному пути, доступному после перезагрузки.

## Работа

- **Ctrl+Shift+A** — выделить область экрана.
- **Ctrl+Shift+Q** — открыть/скрыть ассистента.
- **Ctrl+Shift+C** — скопировать ответ.
- **Esc** — отменить выделение. Правая кнопка мыши также отменяет его.

Горячие клавиши можно изменить; поддерживаются Ctrl/Shift/Alt/Win с латинской буквой, цифрой или F1–F24. Занятое сочетание вызывает предупреждение, прежние регистрации восстанавливаются по возможности.

После выделения проверьте текст, исправьте OCR-ошибки и нажмите «Отправить». Можно ввести вопрос вручную. Режимы: кратко, подробно, пошагово, перевод. Уточняющие вопросы сохраняют контекст текущего диалога. Повтор генерации использует контекст до предыдущего запроса, без дублирования ответа. «Стоп» отменяет ожидание; частичный ответ остаётся видимым, но не попадает в историю и контекст. Пауза отключает захват и отправку.

Если OCR не дал текста, кнопка «Повторить» повторяет распознавание с улучшением контрастности, подавлением шума и резкостью. Стандартный проход сохраняет исходные цвета, увеличивает мелкие фрагменты и ограничивает размер изображения для OCR. Дополнительную обработку можно избежать, вручную исправив текст.

Для сложных формул можно отдельно включить **«Прикрепить выделенное изображение к запросу»**. Изображение загружается в GigaChat через файловый API; модель и тариф должны поддерживать изображения. Автоматическое определение этих возможностей не выполняется: `/models` возвращает список моделей, без гарантии поддержки изображений. Если API отклоняет вложение, отключите флажок и используйте исправленный OCR-текст. Серверные файлы приложение пытается удалить при штатном выходе; при аварии, смене ключа или сетевом сбое удаление не гарантируется. Применяются правила хранения данных провайдера. История содержит только текст, не изображения или их идентификаторы.

Захват выполняется **только по явному действию**. Сначала Qt делает снимки мониторов в памяти, затем показывает оверлеи, поэтому оверлей не попадает в выбранную область. Qt выбран вместо mss для согласованной работы с per-monitor DPI. Выделять можно на любом мониторе, в том числе с отрицательными координатами, но **один прямоугольник должен находиться в пределах одного монитора**.

## Данные и приватность

Настройки, база истории и журнал кодов ошибок хранятся в `%LOCALAPPDATA%\AI Screen Assistant`. Изображения на диск приложением не записываются. По умолчанию автоматическая отправка отключена. При её включении текст отправляется сразу после OCR; изображение автоматически не прикрепляется. Журнал не содержит запросов, ответов API, ключей или скриншотов.

История хранится в локальной SQLite **без шифрования**, содержит текст запросов и ответов. Её можно отключить, искать по ней, удалять отдельные записи и очищать полностью. Отключение записи не удаляет прежние данные. Время записей указано в UTC. Удаление данных из базы не гарантирует уничтожение копий в резервных копиях ОС. Удаление программы сохраняет пользовательские настройки, историю и ключ; для полной очистки удалите указанную папку и запись в Credential Manager самостоятельно.

## Сборка EXE и установщика

На Windows из папки проекта запустите:

```bat
build.bat
```

Скрипт создаёт `.venv`, устанавливает зависимости, проверяет оба языка Windows OCR, запускает тесты, собирает PyInstaller **onedir**, копирует README и запускает smoke-проверку готового EXE. Результат: `dist\AI-Screen-Assistant\AI-Screen-Assistant.exe`. Для распространения нужна **вся папка**, включая `_internal`; Python на целевом ПК не требуется. Компоненты OCR Windows на целевом ПК всё равно нужны. Сборка не подписана цифровой подписью.

Для установщика установите **Inno Setup 6.3+** и после успешной сборки выполните:

```bat
ISCC.exe packaging\installer.iss
```

Результат: `dist\AI-Screen-Assistant-Setup.exe`. Установщик предусматривает каталог установки, ярлыки, необязательную автозагрузку и удаление. Системные языки OCR он не устанавливает. Не запускайте установку поверх работающего приложения без его закрытия через трей.

## Проверки

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe main.py --smoke-test
```

В Linux для GUI smoke-проверки: `QT_QPA_PLATFORM=offscreen python main.py --smoke-test`. Это запуск реальных Qt-окон без рабочего стола и ключей, не проверка Windows OCR или GigaChat.

При разработке выполнены **45 тестов успешно, 4 Windows-теста пропущены**; GUI smoke-проверка и `pip check` прошли. Подробности и ручная приёмка: [TESTING.md](TESTING.md).

## Ограничения

- Требуется проверка на реальном Windows 10/11: OCR RU/EN, Win32 hotkeys, трей, сон/пробуждение, смешанные DPI и собранный EXE. В Linux это не подтверждено.
- Сложные математические формулы и многоколоночный текст могут распознаваться неточно. Поддерживается вывод распространённых формул через локальный mathtext; неподдерживаемый LaTeX показывается текстом. HTML от модели и внешние изображения не загружаются.
- Используется обычная нативная рамка с округлением углов Windows 11 и короткой анимацией появления. Mica/Acrylic и размытие не включены; на Windows 10 оформление углов зависит от ОС.
- Захват защищённых окон, DRM, UAC/secure desktop и некоторых полноэкранных приложений Windows может быть недоступен. Пересечение одного выделения между мониторами не реализовано.
- Лимиты контекста зависят от модели. Приложение ограничивает текст запроса и отбрасывает старые пары диалога по числу символов; точного подсчёта токенов нет.
- Отмена OCR прекращает ожидание результата, но уже начатая короткая операция Windows OCR в рабочем потоке завершается самостоятельно. Непрерывного фонового OCR нет.
